# 灯尽时 · 听雨楼命案

一盏灯灭，六人各怀心事。原创中文版古风悬疑剧本杀，采用雨夜古宅、水墨青绿、纸本卷宗与原创人物立绘。

## 怎样开始

1. 输入名字，创建房间，把邀请链接或五位房间码发给朋友。
2. 每人选择不同角色。固定六席，支持 1–6 位真人；房主可用规则式 AI 补齐。
3. 所有真人准备好后，房主启封故事。
4. 读自己的私人剧本；共三轮，每轮每人搜证两次，可公开线索或密谈。
5. 每轮对证补齐当轮卷宗，提交暂定推理再继续；所有真人确认完成后，房主推进。
6. 秘密提交嫌疑人、关键证据和理由。全员提交后公开答案与逐条推理。

没有自动跳过玩家的倒计时。每幕由真人确认后推进；不因挂机自动得分。案件约 45–60 分钟，按讨论速度自由控制。

## 功能

- 多设备同步房间：服务器权威状态、D1 持久化、1.2 秒轮询、乐观并发控制。
- 六个独立私人剧本：身世、秘密、时间线、个人任务。
- 四处搜证地点、三十六条分轮线索、私人发现与公共卷宗。
- 公聊和一对一密谈；服务器仅向消息双方返回私信。
- 秘密指认，全部提交后才返回完整投票与真相。
- 单人 AI 练习：明确标注为规则式角色；预设口供与公开证据推理，不使用大模型、不需要 AI API key。
- 桌面与手机适配，减少动态效果偏好、键盘焦点、可隐藏的私人剧本。
- 刷新恢复同一席位。一个浏览器标签页对应一个身份；不同设备或独立浏览器可分别加入。

这是原创的固定真相案件，并非商用剧本的复制。重新开始可以换角色，但不会更换凶手。已玩过的朋友请保留真相。

## 本地运行

需要 Node.js 22.13+。

```sh
npm install
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_furry_the_renegades.sql
npm run dev
```

数据库初始化只在全新本地数据库执行一次。开发地址由终端输出，通常为 `http://127.0.0.1:5173`。本地地址只能供本机打开；朋友从其他设备访问需要正式部署或可信局域网配置。

```sh
npm run test:game
npx tsc --noEmit --incremental false
npm run build
```

## 源码边界

- `lib/game/public.ts`：公开人物介绍与规则。
- `lib/game/case.ts`：**含完整剧透，仅由服务器使用**。
- `lib/game/engine.ts`：权限、搜证、阶段、AI与针对每位玩家过滤的视图。
- `app/api/game/route.ts`：认证、D1 CAS 更新与过期房间清理。
- `components/game/`：选角、私人剧本、卷宗、聊天、指认和复盘。

服务端不会把其他角色的私人剧本、未公开线索、私信或未公开投票塞进客户端状态。原始源码仍包含谜底，已阅读源码的人不应以首次玩家身份参与。
