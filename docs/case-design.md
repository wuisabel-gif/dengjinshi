# 案件设计与已知边界

此文件不列出凶手。完整谜底只在服务端 `lib/game/case.ts`，开发者阅读源码会被剧透。

- 身份固定而非随机凶手，保证人物剧本、行程、物证与结局一致。
- 主要推理链包含死因排除、声音来源、进入书房的物证和虚假不在场证明。
- “有动机”“留下物件”“曾经来过”不单独等同于杀人；结局解释每项干扰证据。
- 对证阶段无条件公开十二条线索，确保真人隐瞒或AI保留线索不会把案件锁死。
- 1–6 位真人均可完成；真人必须明确确认每幕和提交指认，服务器不会代选。
- AI是规则式角色。它可公开自己的台词，凶手AI可以说谎；推理只读取公开证据。AI不会自由理解自然语言，密谈回复使用该角色预设口供。
- 个人任务是角色扮演提示，不自动评分。结局明确区分破案结果与凶手是否成为唯一最高票。
- 房间保存24小时。对局开始后不可增补真人或替换席位；断线可用原浏览器标签页刷新恢复。

后续可扩展：更多独立案件、更多分支式角色问答、主持人结束弃局与席位恢复码。目前未承诺这些功能。
